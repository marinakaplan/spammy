# ספאמי · Spammy

> מאיפה יש להם את הטלפון שלי?

כלי קוד פתוח לישראלים: מתעד פניות ספאם, מזהה מי אחראי, ומכין בקשת מחיקה חוקית בלחיצה.

## 💡 למה

חוק הגנת הפרטיות הישראלי מחייב כל גוף למחוק את המידע שלך מהמאגר אם ביקשת. אבל יש **מאות גופים**, לכל אחד פרוצדורה אחרת, וזה לוקח שבועות לעשות ידנית. בעולם קיים הכלי [Unlisted](https://github.com/brightsongwrath/personal-data-deletor-osint) למחיקה ממתווכי מידע בינלאומיים — **ספאמי** הוא הגרסה הישראלית, מותאמת לחוק המקומי.

## 🎯 מה הכלי עושה

- **תיעוד פנייה** — SMS, שיחה, וואטסאפ
- **זיהוי אוטומטי** של הגוף הפונה (מפלגות, בנקים, ביטוחים, סלולר, קמעונאות, לידים)
- **נוסחים משפטיים** בעברית לפי חוק הגנת הפרטיות התשמ"א-1981 (סעיפים 13, 14, 17ו) ו-GDPR Art. 17 לגופים בינלאומיים
- **שליחה המונית** — סמני קטגוריה שלמה, הכלי יכין בקשת מחיקה לכל אחד
- **סריקת ספאמים** — הדביקי ספאמים שהתקשרו, נסמן ספאמרים ידועים
- **מעקב אוטומטי** — תזכורת אחרי 30 יום (זמן התגובה הסטטוטורי)
- **תלונה לרשות להגנת הפרטיות** — אם הגוף התעלם, כפתור אחד ליצירת תלונה
- **ייצוא רשימת חסימה** — CSV לחסימה בטלפון
- **כל הנתונים נשמרים מקומית** — ב-localStorage של הדפדפן, שום דבר לא נשלח לשרת

## 🚀 הפעלה מהירה

```bash

cd spammy

```
